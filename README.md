# Introduction

Weather pattern analysis is an important application of data analytics used to study climatic conditions and identify trends in temperature, humidity, wind speed, pressure, and visibility.

This project focuses on analyzing historical weather data using Python and visualization techniques to discover meaningful insights and seasonal weather patterns.

---

# Objectives

- Analyze historical weather conditions
- Identify temperature and humidity trends
- Perform exploratory data analysis
- Create visualizations for weather attributes
- Study relationships between climatic factors
- Predict temperature using machine learning

---

# Dataset Description

The dataset contains historical weather information with attributes such as:

- Formatted Date
- Summary
- Precip Type
- Temperature (C)
- Apparent Temperature (C)
- Humidity
- Wind Speed (km/h)
- Wind Bearing (degrees)
- Visibility (km)
- Cloud Cover
- Pressure (millibars)
- Daily Summary

The dataset was analyzed using Python libraries including Pandas, Matplotlib, Seaborn, and Scikit-learn.

# Data Preprocessing

The following preprocessing steps were performed:

- Removed missing values
- Removed duplicate records
- Converted formatted date column into datetime format
- Extracted year, month, and day features
- Prepared dataset for visualization and machine learning

---

# Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed to understand weather trends and climatic behavior.

Statistical summaries and visualizations were used to identify important patterns in:

- Temperature
- Humidity
- Wind Speed
- Pressure
- Visibility

---

# Visualizations Performed

The following visualizations were created:

- Temperature Trend Over Time
- Humidity Distribution Histogram
- Correlation Heatmap
- Monthly Average Temperature Chart
- Wind Speed Distribution
- Pressure Variation Analysis
- Scatter Plot (Humidity vs Temperature)
- Weather Condition Frequency Analysis
- Temperature Boxplot

---

# Machine Learning Model

A Linear Regression model was used to predict temperature based on:

- Humidity
- Wind Speed
- Pressure
- Visibility

The dataset was divided into training and testing sets.

Model performance was evaluated using:

- Mean Absolute Error (MAE)
- R² Score

---

# Key Findings

- Temperature varies significantly across seasons
- Humidity strongly affects weather conditions
- Pressure variations indicate climate fluctuations
- Wind speed remains moderate during most periods
- Correlation analysis revealed relationships between climatic factors
- Linear Regression successfully predicted temperature with good accuracy
